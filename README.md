# Vokasitera
<img width="2879" height="1634" alt="image" src="https://github.com/user-attachments/assets/a5792d76-f0bb-4e13-8405-d17f35c9142d" />

Vokasitera merupakan aplikasi berbasis web/mobile yang dikembangkan untuk membantu pengelolaan dan digitalisasi layanan pengumpulan proyek AKhir Mahasiswa vokasi IT DEL secara modern, efisien, dan terintegrasi.

# Tentang Project

Vokasitera dikembangkan sebagai solusi digital untuk mendukung proses manajemen pendidikan vokasi, mulai dari pengelolaan data pengguna, monitoring aktivitas pengumpulan progress dan monitoring proyek akhir, hingga penjadwalan seminar dan penilaian , visualisasi data berbasis dashboard.

Project ini dirancang menggunakan arsitektur modern dengan pemisahan backend, dan frontendagar mudah dikembangkan dan di-maintain.

# Fitur Utama

* Autentikasi dan Authorization JWT
* Dashboard Monitoring
* Manajemen Data Pengguna
* REST API Backend untuk mobile
* Responsive User Interface
* Role Management
* Logging dan Error Handling
* Integrasi Database MYSQL
